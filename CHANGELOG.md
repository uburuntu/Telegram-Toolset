# Changelog

This project evolved from Telegram Deleted Messages Manager, a desktop utility, into Telegram
Toolset, a browser-based modular workspace. Current development happens on `main`; pull requests and
their preview deployments document unreleased changes.

## Current Web Application

The maintained product is available at [telegram-toolset.rmbk.me](https://telegram-toolset.rmbk.me/).
Its tool surface includes account inspection, deleted-message export, local backups, resend,
scheduled messages, reviewed deletion of the current user's messages, and LLM context export.
